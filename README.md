# JSONFlow - View JSON as Tree

This project allows users to upload, preview, manage, and download JSON. It includes search functionality, supports copy path.

---

## 🚀 Live Demo
👉 [Click here to try JSONFlow](https://json-flow-ivory.vercel.app/)

---

## 🔑 Key Features

- ✅ **Responsive UI**
- 🔍 **Real-time Search**
- 📁 **Visualize JSON**
- ⚡ **Download JSON as Image**
- ☀️ **View Mode (Dark/Light)**
- 🔍 **Zoom In/Out & Fit Screen**
